# အခန်း ၅ ဇာတ်သိမ်း script — အဆိုပြုမူကြမ်း

ဤဖိုင်သည် ကနဦးဆွေးနွေးမူကြမ်းဖြစ်သည်။ အသုံးပြုသူက final fight ကိုပါ အသေးစိတ်စဉ်းစားပေးရန် တောင်းဆိုပြီးနောက် **ဦးကြီး boss၊ ဒိုင်းနှင့်နှစ်ဖက်သုံးလှည်း ပါသော နောက်ဆုံးအဆိုပြု script** ကို [chapter5_final_boss_proposal.md](chapter5_final_boss_proposal.md) တွင် သီးခြားရေးထားသည်။ ယခုဖိုင်မှ မရွေးရသေးကြောင်းစာသားများကို ယခင်ဆွေးနွေးမှုအဖြစ်သာဖတ်ပါ။

ရေးသည့်ရက်: 2026-10-29။ အသုံးပြုသူက အခန်း၅တွင် ဇာတ်သိမ်းလိုကြောင်း မေးမြန်းသည့်အတွက် ရေးထားသော ဆွေးနွေးရန်မူကြမ်းဖြစ်သည်။ Gameplay spec အတည်ပြုချက်၊ implementation ခွင့်ပြုချက် သို့မဟုတ် တည်ဆောက်ပြီးအခန်း မဟုတ်ပါ။ လက်ရှိ CHAPTER_5_PENDING ကို မပြောင်းထားပါ။

အသုံးပြုသူ၏ နောက်ဆုံးပြင်ဆင်ချက်: **အခန်း၅တွင် fighting ပါရမည်။** နောက်ဆုံးရန်သူကို မရွေးရသေးပါ။ ဦးကြီးကိုယ်တိုင် boss လုပ်ရန်မှာ အကြံပြုချက်သာဖြစ်ပြီး အတည်ပြုထားသောဆုံးဖြတ်ချက် မဟုတ်ပါ။

## အကြံပြုဇာတ်သိမ်း — «ဦးကြီးရဲ့ နောက်ဆုံးအကွက်»

အဓိကဆုံးဖြတ်ချက်မှာ **ရွှေမြို့တော်၏ ရှေးဟောင်းအပျက်အစီးများက တကယ်ရှိသည်။ ဦးကြီးပြသည့် နောက်ဆုံးရွှေပုံကြီးသာ အတုဖြစ်သည်** ဟူသော reveal ဖြစ်သည်။ လာခဲ့သမျှခရီးနှင့် တကယ်ကောက်ထားသောရွှေကို အလကားဖြစ်သွားစေမည့် အဆုံးသတ်မျိုး မသုံးရန် အကြံပြုသည်။ ဦးကြီး၏ လမ်းပြဟန်ဆောင်လိမ်လည်မှုနှင့် မိမိထောင်ချောက်ကို ပြန်အသုံးချခြင်းက ဇာတ်သိမ်း၏ အဓိကဖြစ်မည်။

အသက်ရှင်လွတ်မြောက်ခြင်းက အဓိကအောင်မြင်မှု၊ ရွှေဖြင့်အကြွေးပါကျေနိုင်လျှင် ပိုကောင်းသောအဆုံးသတ် ဟူသည့် အတည်ပြုပြီးဆုံးဖြတ်ချက်ကို ထိန်းသည်။ အကြွေးပမာဏ၊ ရွှေရုပ်တန်ဖိုး၊ Chapter5 reward amount မသတ်မှတ်ပါ။

## Scene 1 — လူဝံခန်းနောက်က ရွှေခန်း

**မြင်ကွင်း:** အခန်း၄ရဲ့ ကျောက်တံခါးကို ကျော်လာသည်။ ပျက်စီးနေသော ရှေးဟောင်းအတွင်းခန်းကို နေရောင်ဝင်နေသည်။ အလယ်ရှိ သံလမ်းပေါ်က လှည်းထဲတွင် ရွှေရောင်တုံးများ ပုံထားသည်။ ညာဘက်ထွက်ပေါက်ကို သစ်သားကန့်တားတန်း ပိတ်ထားသည်။ ဦးကြီးကို အခန်းဘေးက ဘရိတ်ကြိုးများရှိသည့်နေရာတွင် ပထမဆုံး ရှင်းရှင်းတွေ့ရသည်။

**ဦးကြီး:** «ရောက်ပြီ ဖိုးထောင်ရေ။ ဒီလှည်းကို ငါ့ဘက် တွန်းပို့လိုက်။ ရွှေတွေ ခွဲပေးမယ်။»

**ဖိုးထောင်:** «လူဝံနှစ်ကောင်ကို ကျုပ်ချခဲ့တာနော်။ ကျုပ်အတွက် များများချန်ထားဦး။»

ဤအဖွင့်ကို တိုတိုထားရန်။ Subtitle ကိုဖတ်ပြီး ဆက်နိုင်စေရန်၊ ရှည်လျားသောမကျော်နိုင်သည့် cutscene မသုံးရန် အကြံပြုသည်။

## Scene 2 — လမ်းပြ၏ အကြံအစည်

လှည်းပေါ်က ရွှေရောင်တုံးတစ်တုံး လှုပ်ပြီး အပေါ်ယံရွှေဆေး ကွာကျသည်။ အတွင်းက သာမန်ကျောက်တုံးဖြစ်ကြောင်း မြင်ရသည်။ ဖိုးထောင်၏ အိတ်ထဲက အမှန်တကယ်ကောက်ထားသည့်ရွှေကို မပျောက်စေပါ။

**ဖိုးထောင်:** «ဦးကြီး... ရွှေက အခွံကွာလို့ရတာလား?»

**ဦးကြီး:** «ဟဲဟဲ... မင်းရလာတဲ့အိတ်ကို ဒီမှာထားခဲ့။ အပြန်လမ်းကိုတော့ ငါပြပေးမယ်။»

**ဖိုးထောင်:** «အစကတည်းက ကျုပ်အိတ်ကို မျက်စိကျနေတာပေါ့။»

**ဦးကြီး:** «မင်းက ရွှေရှာလာတာ။ ငါက ရှာပြီးသားသူကို စောင့်နေတာကွ။»

ဦးကြီးက လမ်းပြအဖြစ် ယုံကြည်မှုယူပြီး အခန်းများကို ဖြတ်ကျော်လာနိုင်သူ၏ ရလာဒ်ကို လိမ်ယူရန် ကြံစည်ကြောင်း ထင်ရှားစေသည်။ သူသည် ရှေးမြို့တော်တစ်ခုလုံးကို တည်ဆောက်ထားသူ သို့မဟုတ် အရာရာထိန်းနိုင်သည့်မှော်ဇာတ်ကောင် မဟုတ်ပါ။ ငွေကြေးလွှဲယူသည့် transaction ကို cutscene က အလိုအလျောက်မလုပ်ရ။

## Scene 3 — နောက်ဆုံးတိုက်ပွဲ

ဦးကြီး၏အကြံအစည် ပေါ်လာပြီးနောက် ဖိုးထောင်၏အိတ်ကို လုယူရန် ရင်ဆိုင်လာမည်။ ကစားသူက ကိုယ်တိုင်ထိန်းချုပ်၍ နောက်ဆုံးတိုက်ပွဲကို ကစားရမည်။ ယခင်မူကြမ်း၏ လှည်းပဟေဠိတစ်ခုတည်းဖြင့် climax ပြီးသွားမည့်အစီအစဉ်ကို ဤတိုက်ပွဲက အစားထိုးသည်။

အကြံပြုရန်သူမှာ ဦးကြီးကိုယ်တိုင်ဖြစ်သည်—တစ်လျှောက်လုံး ဒုက္ခပေးလာသူနှင့် နောက်ဆုံးရင်ဆိုင်ရခြင်းက ဇာတ်လမ်းကို ပိတ်နိုင်သောကြောင့်ဖြစ်သည်။ အသုံးပြုသူက ဦးကြီး သို့မဟုတ် သူ၏လူကို ရွေးပြီးမှ စကားပြောနှင့်တိုက်ပွဲကို အပြီးရေးမည်။

ယာယီ pre-fight dialogue:

**ဦးကြီး:** «အိတ်ချထားခဲ့။ မင်းအိမ်ပြန်ရမယ်။»

**ဖိုးထောင်:** «လမ်းတစ်လျှောက်လုပ်ထားသမျှအတွက် စာရင်းရှင်းဖို့ ကျန်သေးတယ်။»

ရန်သူ၏လက်နက်၊ တိုက်ကွက်၊ phase၊ သွေးပမာဏနှင့် အနိုင်ရစည်းမျဉ်း မသတ်မှတ်သေးပါ။ အခန်း၄၏ လက်ချည်းစခြင်း၊ အိတ်မှလောက်လေးခွထုတ်သုံးခြင်းကို ဆက်စဉ်းစားမည်။ အခန်း၅တွင် လောက်လေးခွမပါဘဲ အနိုင်ရနိုင်မနိုင်ကို Chapter4 စည်းမျဉ်းမှ အလိုအလျောက်မကူးယူရ။

## Scene 4 — တိုက်ပွဲအပြီးနှင့် ထွက်ပေါက်

တိုက်ပွဲကို အနိုင်ရပြီးနောက် ဦးကြီး၏အကြံအစည် ပျက်သွားကြောင်းနှင့် အပြန်လမ်းရလာကြောင်း ပြမည်။ နောက်ဆုံးရန်သူပေါ်မူတည်ပြီး ဦးကြီး၏ ဟာသအရှုံးကို ရေးမည်။ ယခင်ရွှေအတုလှည်းကို ထွက်ပေါက်ဖွင့်ရာ၌ သုံးသည့်အပိုင်းကို လိုအပ်မှ တိုတောင်းသောအပိုင်းအဖြစ် ဆက်ထားနိုင်သည်။ ထိုလှည်း mechanic ကို အတည်မပြုထားပါ။

ကစားသူက ဖိုးထောင်ကို ထိန်းပြီး ထွက်ပေါက်ကို တကယ်ကျော်ရမည်။ အနိုင်ရပြီးမှ ရုတ်တရက်သတ်သည့် gag မသုံးရ၊ အမှန်တကယ်ကောက်ထားသောရွှေကို မဖျက်ရ။

## Scene 5 — အပြင်ကမ္ဘာနှင့် ပြီးဆုံးခြင်း

ဖိုးထောင် ထွက်ပေါက်ကို တကယ်ကျော်ပြီးသည်နှင့် အပြင်က နေရောင်၊ ရှေးမြို့အပျက်အစီးနှင့် အိမ်ပြန်လမ်းကို မြင်ရမည်။ အခန်း၁–၄တွင် ရွှေမြို့တော်ကိုရှာလာခဲ့သည့် ခရီးရှိခဲ့ကြောင်း ဤမြင်ကွင်းက အတည်ပြုမည်။

**ဖိုးထောင်:** «ရွှေမြို့တော်တော့ တွေ့ခဲ့ပြီ။ အိမ်ပြန်လမ်းက ပိုရှာရခက်သား။»

ထို့နောက် တကယ်သိမ်းထားသည့်ရွှေနှင့် အတည်ပြုရန်ကျန်သည့် အကြွေးစည်းမျဉ်းအရ epilogue ကွဲမည်။

### အဆုံးသတ် A — လွတ်လာပြီ

ရွှေမလောက်လည်း အဓိကဂိမ်းပြီးဆုံးမှု အပြည့်ရမည်။ ရခဲ့သည့်ရွှေသည် အကြွေးတချို့ဆပ်ရန် ဆက်အသုံးဝင်မည်။ ရွှေသုညဆိုလည်း အသက်ရှင်လွတ်မြောက်ခြင်းအတွက် အောင်မြင်မှုပြမည်။ မရသည့်ရွှေကို အလကားဖန်တီးမပေးပါ။

**ဖိုးထောင်:** «ဒီတစ်ခါတော့ အသက်ပါလာပြီ။ ကျန်တာ ဖြည်းဖြည်းချင်း ရှင်းတော့မယ်။»

### အဆုံးသတ် B — အကြွေးကျေပြီ

လုံလောက်သောရွှေယူထွက်နိုင်ခဲ့လျှင် အကြွေးဆပ်ပြီး အိမ်ပြန်နိုင်သည့် ပိုကောင်းသော epilogue ပြမည်။ Debt threshold ကို earning budget နှင့် Chapter3 relic valuation ဆုံးဖြတ်ပြီးမှ သတ်မှတ်ရမည်။ ဤမူကြမ်းက ငွေပမာဏ သို့မဟုတ် payout အသစ် မထည့်ပါ။

**အကြွေးရှင်:** «ကဲ... အကြွေးကျေပြီ။ နောက်ဘာလုပ်ဦးမလဲ?»

**ဖိုးထောင်:** «အိမ်ပြန်မယ်။ ဒီတစ်ခါ လမ်းတော့ ကိုယ့်ဟာကိုယ်ရွေးမယ်။»

အဆုံးသတ်နှစ်ခုလုံးတွင် ရလာဒ်၊ credits၊ ကိုယ်တိုင်ရွေးနိုင်သည့် chapter replay/menu ကို ပြနိုင်သည်။ အဆုံးသတ်အောက်က ခလုတ်ကို ရှောင်ခိုင်းခြင်း၊ victory စာတန်းဖြင့်ဖိသတ်ခြင်း၊ ရှင်းပြီးမှ အတင်းသေဆုံးစေခြင်း၊ Chapter6 ကိုမဖြစ်မနေဆက်ခိုင်းခြင်း မလုပ်ပါ။

## မူကြမ်း၏ကန့်သတ်ချက်

ခန့်မှန်းရည်ရွယ်ချက်မှာ ပထမအကြိမ်ကစားချိန်3–5မိနစ်ခန့်၊ သိပြီးသားလမ်းကြောင်းက ပိုတိုနိုင်သည်။ ဆွေးနွေးရန်ပမာဏသာဖြစ်ပြီး ကစားစမ်းသပ်ထားခြင်း မရှိပါ။ ဇာတ်သိမ်းကိုရှည်စေရန် cutscene၊ အတင်းစောင့်ချိန်၊ ထပ်တူတိုက်ပွဲဖြင့် မဖြည့်သင့်ပါ။

တိုက်ပွဲပါဝင်ခြင်းကို အသုံးပြုသူက တောင်းဆိုထားသည်။ နောက်ဆုံးရန်သူ၊ ရွှေခန်း reveal၊ fight mechanics နှင့် အပိုလှည်းအစီအစဉ်ကို အတည်မပြုရသေးပါ။ ယခုအဆင့်တွင် code၊ runtime constants၊ save/ending payout၊ assets၊ server၊ GitHub branch ကို မပြောင်းထားပါ။

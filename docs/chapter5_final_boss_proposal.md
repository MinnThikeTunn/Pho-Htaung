## 1. ရွေးချယ်ချက်နှင့် အကြောင်းရင်း

**ဦးကြီးကိုယ်တိုင်က နောက်ဆုံး boss ဖြစ်မည်။** တစ်လျှောက်လုံး သူ့စကားနောက်လိုက်ရင်း ဒုက္ခတွေဖြတ်ခဲ့သော ဖိုးထောင်က နောက်ဆုံးတွင် သူနှင့်တိုက်ရိုက်ရင်ဆိုင်ရမည်။ ကစားသူသိထားပြီးသော လူတစ်ယောက်နှင့် စာရင်းရှင်းရခြင်းက ဇာတ်သိမ်း၏ စိတ်ခံစားမှုကိုပေးမည်။

ဦးကြီးသည် သံတိုသံစများ၊ စက်ကိရိယာနှင့် လူလိမ်အကြံကို အသုံးချတတ်သည့် လူဖြစ်မည်။ ရွှေရောင်သုတ်သံပြားကို ဒိုင်းလုပ်ပြီး လှည်းထိန်းတုတ်ဖြင့်ချမည်။ လူဝံထက်ကြီးသောကိုယ်၊ မှော်အစွမ်း၊ ပုံစံပြောင်းခြင်း မလိုပါ။

Chapter4 က ရန်သူနှစ်ကောင်အကြား တိုက်ပွဲဖိအားကို ကိုင်တွယ်ရသည့်အခန်း။ Chapter5 က **ဒိုင်းဖွင့်သွားသည့်အချိန်၊ ရပ်နေသည့်ဘက်နှင့် နှစ်ဖက်လုံးသုံးနိုင်သောလှည်း** ကို စဉ်းစားရသည့် boss fight ဖြစ်မည်။ အဓိကအသစ်မှာ လှည်းတစ်စီး၏ နှစ်ဖက်အကျိုးသက်ရောက်မှုသာဖြစ်သည်။

## 2. နေရာ၊ ပစ္စည်းနှင့် အဖွင့်အခြေအနေ

အခန်း၄ကျောက်တံခါးနောက်တွင် နေရောင်ဝင်နေသော ရှေးဟောင်းရွှေခန်းရှိမည်။ အရောင်နှင့်ပစ္စည်းအသွင်ကို Chapter3/4 နှင့်ညှိထားမည်—ဟောင်းနွမ်းသောကျောက်၊ ရွှေရောင်အလှဆင်အကြွင်းအကျန်၊ သစ်မြစ်များ၊ ကျိုးပျက်အမိုးနှင့် နွေးသောအလင်း။

ကစားရာအဓိကနေရာတွင် အနှောင့်အယှက်နည်းသောမြေပြင်၊ အလယ်က သံလမ်းလှည်းတစ်စီး၊ ညာဘက်က ပိတ်ထားသောအပြန်တံခါးနှင့် ဦးကြီးရှိမည်။ လှည်းတွင် ရွှေရောင်ကျောက်တုံးများတင်ထားသည်။ အရာအားလုံးကို ပဟေဠိအဖြစ် မလုပ်ပါ။

ဖိုးထောင်သည် Chapter4 နှင့်တူသည့် မျက်နှာ/ပုဆိုး/လှုပ်ရှားမှု၊ A/D၊ Space၊ J၊ K၊ L၊ B controls ကို ဆက်သုံးမည်။ အစမှာလက်ချည်း၊ ပိုင်ဆိုင်လာသောလောက်လေးခွကို B အိတ်မှရွေးထုတ်မှ K ပစ်နိုင်မည်။ Chapter5 အတွက် skill ခလုတ်အသစ် မထည့်ရန် အကြံပြုသည်။

အဖွင့်စကားပြောအတွင်း အန္တရာယ်မစရ။ စာဖတ်ပြီး ဆက်ခြင်း သို့မဟုတ် skip ပြုလုပ်နိုင်စေရန်။ Retry မှာ ရှည်သော intro ပြန်မကြည့်ရ။ B အိတ်ဖွင့်ထားချိန်မှာ လက်ရှိ Chapter4 ကဲ့သို့ simulation/time ရပ်ပြီး held input ကိုရှင်းမည်။

## 3. Scene 1 — ရွှေခန်းသို့ရောက်ခြင်း

ကင်မရာက အလယ်ကရွှေပုံ၊ လှည်းနှင့် ဦးကြီးကို တိုတိုပြမည်။

**ဦးကြီး:** «ဖိုးထောင်ရေ... ရောက်လာပြီပေါ့။ လူဝံနှစ်ကောင်ကိုပါ ကျော်လာနိုင်တယ်ဆိုတော့ မင်း မဆိုးဘူးကွ။»

**ဖိုးထောင်:** «လမ်းကောင်းတယ်ဆိုပြီး ခေါ်လာတာနော်။ လမ်းတစ်လျှောက် ကျုပ်ပဲ ရှင်းနေရတာ။»

**ဦးကြီး:** «အဲဒါကြောင့် ဆုရှိတာပေါ့ကွာ။ ဟောဒီရွှေတွေကို ကြည့်စမ်း။»

ဤအပိုင်းက စကားပြောကြောင့် အကြမ်းဖျင်း20–30စက္ကန့်အတွင်းပြီးရန် ရည်ရွယ်မည်။ အချိန်ဖြည့်ရန် စာဖတ်စောင့်ခိုင်းခြင်း မဟုတ်ပါ။

## 4. Scene 2 — လိမ်လည်မှုကို သိခြင်း

ဦးကြီးက လှည်းပေါ်ကတုံးတစ်တုံးကို ခေါက်ပြရင်း ရွှေဆေးကွာကျပြီး သာမန်ကျောက်ဖြစ်ကြောင်း တွေ့ရမည်။

**ဖိုးထောင်:** «ဦးကြီး... ရွှေက အခွံကွာလို့ရတာလား?»

**ဦးကြီး:** «အဲဒါတွေထားလိုက်။ မင်းကောက်လာတဲ့အိတ်ကို ဒီမှာချခဲ့။ အိမ်ပြန်လမ်းကို ငါပြပေးမယ်။»

**ဖိုးထောင်:** «ကျုပ်ကို လမ်းရှင်းခိုင်းပြီး အခု အိတ်ပါယူဦးမယ်ပေါ့။»

**ဦးကြီး:** «အေးအေးဆေးဆေးပြောနေတုန်း ပေးလိုက်ပါကွာ။»

**ဖိုးထောင်:** «ဒီတစ်ခါတော့ ခင်ဗျားနဲ့ စာရင်းရှင်းရမယ်။»

ဦးကြီးက တံခါးသော့ကို ခါးတွင်ချိတ်၊ သံပြားဒိုင်းနှင့်တုတ်ကို ကိုင်ပြီးတိုက်ရန်ပြင်မည်။ ရန်သူသွေးတန်းပေါ်လာပြီး ကစားသူက ဆက်/skip ပြီးနောက် တိုက်ပွဲစမည်။

**ဇာတ်လမ်းအဓိပ္ပာယ်:** ရှေးမြို့တော်က တကယ်ရှိသည်။ ဦးကြီးက ထိုနေရာကို အသုံးချပြီး လမ်းဖြတ်ကျော်လာနိုင်သူများ၏ ရရှိသမျှကို လိမ်ယူရန်စောင့်နေသည်။ နောက်ဆုံးရွှေပုံကြီးသာ အတု။ ယခင်အခန်းမှ currency/relic မပျက်ရ၊ အိတ်ကို cutscene ကြောင့်အလိုအလျောက်မဆုံးရှုံးရ။

## 5. တိုက်ပွဲ၏ အဓိကစည်းမျဉ်း

ဦးကြီးက **ဒိုင်းရှေ့ကနေ ကာထားသည့်ဘက်** ကို အဆက်မပြတ်ပစ်ရုံဖြင့် မနိုင်ရ။ ဒိုင်းထိလျှင် သံခေါက်သံ၊ ဒိုင်းတုံ့ပြန်ပုံနှင့် ကာထားကြောင်းကို ပြမည်။ ထိရောက်မှုမရှိဘဲ HP လျော့ပြခြင်း မလုပ်ရ။ သို့သော် တိုက်ပွဲတစ်ခုလုံး ပုံသေအချိန်စောင့်ပြီးမှတစ်ချက်သာချနိုင်သည့်ပုံစံ မဖြစ်စေရ။

ကစားသူတွင် အခွင့်အရေးအမျိုးမျိုးရှိမည်:

- တုတ်ကြီးချလိုက်ပြီး ပြန်မတင်နိုင်သေးချိန် ရှောင်ပြီးအနားကပ် J ချနိုင်မည်။
- တိုးဝင်လာစဉ် နောက်ဘက်သို့လွတ်သွားလျှင် ပိတ်မထားသောဘက်ကို ချ/ပစ်နိုင်မည်။ တိုက်ကွက်စပြီးနောက် ရုတ်တရက်လှည့်ကာခြင်း မဖြစ်ရ။
- လှည်းနှင့်တိုးတိုက်မိ၍ ဒိုင်းဖွင့်သွားသည့် ပိုကြာသောနားချိန်တွင် ပြန်ချနိုင်မည်။

J လက်သီးဖြင့်လည်း Chapter5 boss ကိုနိုင်နိုင်ရန် အကြံပြုသည်။ ဦးကြီးသည် လူဝံနှင့်အတူတူသော ခုခံနိုင်စွမ်းမဟုတ်သောကြောင့် Chapter5 တွင် exposed-body punch ထိရောက်မှုကို သီးခြားချိန်မည်။ Chapter4 ၏ punch constants ကိုမပြောင်းရ။ လောက်လေးခွက အကွာအဝေးနှင့် အားပြည့်တစ်ချက်၏ အကျိုးပိုပေးမည်။ လက်နက်ရှိ/မရှိက ending အမျိုးအစားကိုမဆုံးဖြတ်ရ။

## 6. ပထမပိုင်း — ဒိုင်းနှင့်တုတ်

### တိုက်ကွက် A — အပေါ်မှတုတ်ရိုက်

တုတ်ကို ထောင်မြှောက်ပြီး ထိမည့်နေရာကို မြေပြင်ပေါ်တိတိကျကျပြမည်။ ထိုနေရာကိုသာ ချမည်။

**တုံ့ပြန်ပုံ:** ဘေးရွေ့ သို့မဟုတ် L ဖြင့်ရှောင်ပါ။ အဲဒီနေရာတင် ခုန်နေရုံက တုတ်ကျလာသည့်ဧရိယာကို မလွတ်နိုင်ပါ။

လွဲသွားသောတုတ်ကို ပြန်တင်နေစဉ် ဒိုင်းဖွင့်မည်။ ထိုအချိန်မှာ နီးလျှင် J၊ အကွာအဝေးနှင့်အချိန်ရလျှင် K ဖြင့်ပြန်တိုက်နိုင်မည်။

### တိုက်ကွက် B — ဒိုင်းနှင့်တိုးဝင်

ဒိုင်းကိုရှေ့တင်၊ ကိုယ်ကိုငုံ့၊ တိုးမည့်လမ်းကြောင်းကို မြင်သာစွာပြမည်။ စပြီးနောက် ဦးတည်ရာကို မလိုက်ပြောင်းရ။

**တုံ့ပြန်ပုံ:** ခုန်ကျော်၊ အချိန်ကိုက် L ဖြင့်ဖြတ်ရှောင်၊ သို့မဟုတ် တိုးလာမည့်လမ်းတွင် လှည်းကို ကြိုတင်နေရာယူထားနိုင်မည်။

လွတ်သွားသောဦးကြီးက နောက်ပြန်လှည့်ရန် အချိန်ယူရမည်။ သူ့ဒိုင်းမကာထားသောဘက်ကို တိုက်နိုင်မည်။

### လှည်း၏ နှစ်ဖက်အကျိုးသက်ရောက်မှု

လှည်းကို A/D ဖြင့်ကပ်တွန်းပြီး နေရာပြောင်းနိုင်မည်။ Player taunt ခလုတ်ဖြင့် ရန်သူကိုခေါ်ခြင်း မရှိပါ။

- ဦးကြီးတိုးဝင်ပြီး လှည်းကိုတိုက်မိလျှင် ခဏကြာနားပြီး ဒိုင်းဖွင့်မည်။
- လှည်းက ကျောက်ခဲလမ်းကြောင်းကို ပိတ်နိုင်သဖြင့် ကိုယ့် K ပစ်ချက်ကိုလည်း ပိတ်နိုင်မည်။ လှည်းပေါ်ခုန်တက်ပြီး အပေါ်မှပစ်ခြင်း သို့မဟုတ် လှည်းကိုကျော်၍ ပွင့်နေသောဘက်မှချခြင်း လိုလာမည်။ လှည်းသည် တက်ရပ်နိုင်သောအမြင့်နှင့် shared jump ဖြင့်ကျော်နိုင်သောအရွယ်ဖြစ်ရမည်။ 2D ဂိမ်းတွင် မရှိသော screen-depth လမ်းကိုဖြတ်လျှောက်နိုင်သလို မရေးရ။
- လှည်းကိုသာထပ်ခါတွန်းရုံဖြင့် boss HP မကုန်ရ။ လှည်း၏အဓိကအကျိုးက တိုက်ခိုက်ခွင့်ဖန်တီးခြင်းဖြစ်သည်။
- လှည်းမသုံးဘဲ တုတ်ရိုက်ပြီးနားချိန်/နောက်ဘက်မှ ပြန်ချသည့်နည်းလည်း အလုပ်လုပ်ရမည်။ လှည်းတိုးတိုက်သည့်အကြိမ်အရေအတွက်ကို လျှို့ဝှက် exit requirement မလုပ်ရ။

ဤအရာက လှည်းကို «အမြဲအကျိုးရှိသောကာကွယ်ရေးပစ္စည်း» ဖြစ်သွားခြင်းမှ ရှောင်စေသည်။ နေရာကောင်းတွင်ထားလျှင် အခွင့်အရေးရပြီး မိမိပစ်ချင်သည့်လမ်းကို ပိတ်မိလျှင် ပြန်နေရာရွေးရမည်။

## 7. ဒုတိယပိုင်း — ဦးကြီးက လှည်းကိုပြန်သုံးခြင်း

သွေးတစ်ဝက်ခန့်ကျသည့်နောက် ရှိပြီးသားတိုက်ကွက်များနှင့်အတူ လှည်းတွန်းတိုက်သည့် တိုက်ကွက်ထပ်ပါမည်။ ဦးကြီးသွေးပြန်မပြည့်ရ၊ cutscene အတွင်း မထိခိုက်နိုင်သောအချိန်ရှည် မထည့်ရ။

**ဦးကြီး:** «ရပြီ၊ ရပြီ... ငါက စနောက်တာပါကွာ။»

ဒါပေမယ့် သူက လှည်းနားရောက်ပြီး နှစ်လက်ဖြင့်တွန်းရန် ပြင်နေသည်။ လက်နက်နှင့် လှုပ်ရှားမှုကို ကစားသူမြင်နိုင်ပြီး သွေးတန်းက ရှိနေဆဲဖြစ်မည်။ «တိုက်ပွဲပြီးပြီ» ဟု UI က မလိမ်ရ။ ကစားသူစကားနားထောင်ရန် လှုပ်ရှားမှုရပ်ခိုင်းခြင်း မလုပ်ရ။

### တိုက်ကွက် C — လှည်းတွန်းတိုက်

ဦးကြီးက လှည်းဆီ ကိုယ်တိုင်သွား၊ နှစ်လက်တင်၊ တွန်းမည့်ဘက်ကို ပြပြီးမှ တွန်းမည်။ အဝေးကနေ လှည်းအလိုအလျောက်ပျံလာခြင်း မဖြစ်ရ။

**တုံ့ပြန်ပုံနှစ်မျိုး:**

1. တွန်းရန်ပြင်စဉ် ဒိုင်းချထားသော ဦးကြီးကို J သို့မဟုတ် K ဖြင့်တိုက်ပြီး တွန်းခြင်းကိုတားနိုင်မည်။ ရှင်းရှင်းပြထားသော ဒီအားနည်းချက်က သာမန်တုတ်ရိုက်တိုက်ကွက်တိုင်းကို stun-lock လုပ်ခွင့် မပေးပါ။
2. လှည်းလွှတ်ပြီးသွားလျှင် ခုန်ကျော်ပြီး တိုက်ပွဲနေရာကို ပြန်ရွေးနိုင်မည်။ ဦးကြီးက ပြန်ဒိုင်းတင်နေချိန် အခွင့်အရေးရှိမည်။

လှည်းက ဆင်းလျှောသွားပြီးနောက် နံရံ/ရထားတားအဆုံးတွင် ရပ်ကာ ပြန်တွန်းနိုင်ရမည်။ တစ်ခါလွဲလျှင်အခန်းပိတ်သွားခြင်း၊ အိတ်ထဲကရွှေကိုအစားထိုးထည့်မှရခြင်း မရှိရ။ လှည်းမရောက်နိုင်သည့်အနေအထားတွင် AI က ရှိပြီးသားတိုက်ကွက်ကိုသုံး၍ တိုက်ပွဲဆက်နိုင်ရမည်။

## 8. Prototype စမ်းရန် စမှတ်ကိန်းများ

ဤကိန်းများသည် **ဆွေးနွေးပြီး graybox စမ်းရန် အဆိုပြုချက်သာ** ဖြစ်သည်။ လက်ရှိ runtime code/constants မဟုတ်ပါ။ သင်္ချာတစ်ခုတည်းဖြင့် fun/balance ကို အာမခံမရပါ။

| အချက် | အဆိုပြုစမှတ် |
|---|---:|
| ဖိုးထောင် စသွေး |100|
| ဦးကြီး စသွေး |180|
| ဒုတိယပိုင်း စမည့်သွေး |90 သို့အောက်; လုပ်နေသောတိုက်ကွက်ပြီးမှ ပုံစံသစ်ရွေး |
| ဖွင့်နေသောကိုယ်ထိ J |10; Chapter5 boss အတွက်သာ |
| အားပြည့် K |30; Chapter4 နှင့်တူ |
| ဒိုင်းဖြင့်ကာမိသောပစ်ချက်/လက်သီး |0; ရှင်းသော block feedback ပြရန် |
| အပေါ်မှတုတ် warning / recovery |0.8s /1.3s|
| ဒိုင်းတိုးဝင် warning |0.9s; ဦးတည်ရာကို lock ပြီးမှတိုး |
| တိုးဝင်ပြီးလှည်းနှင့်တိုက်မိလျှင် opening |2s|
| လှည်းတွန်းမည့် warning |0.9s|
| ရန်သူ့တုတ် / ဒိုင်းတိုး / လှည်းထိ damage |24 /20 /24|

ရှိပြီးသားလောက်လေးခွ draw0.55s၊ movement/jump၊ dodge၊ hurt grace၊ charge interruption ကို စတင်စမ်းသပ်စဉ် ယူသုံးနိုင်မည်။ တိုက်ကွက်နှစ်ခုကို တစ်ပြိုင်နက်မစရ၊ လှည်းအန္တရာယ်နှင့် နောက်တိုက်ကွက်က ပေါင်း၍မလွတ်နိုင်သောအခြေအနေ မဖြစ်ရ။ Hitboxes နှင့် art အရွယ်အစားကို သီးခြားသတ်မှတ်ရမည်။

လောက်လေးခွပိုင်ဆိုင်လာသူတွင် စတင်ကျောက်ခဲ12ခဲနှင့် Chapter4 ကဲ့သို့ အနားရှိကျောက်ပုံများမှ ပြန်ဖြည့်နိုင်မှုကို ယူသုံးရန် အကြံပြုသည်။ ရွှေမကုန်ရ၊ လက်နက်မပါသူကို ကျောက်ပုံကလက်နက်အလိုအလျောက် မပေးရ။ ကျောက်ခဲကုန်သွားလျှင် အိတ်မှလက်ချည်းပြန်ရွေးပြီး တိုက်ပွဲဆက်နိုင်သည်။

Chapter5 တွင်75စက္ကန့်ပြည့်လျှင် အလိုအလျောက်ရှုံးသည့် deadline ကို အကြံမပြုပါ။ တိုက်ပွဲချိန်ကို result/replay မှတ်တမ်းအဖြစ်ပြနိုင်သည်။ သွေးကုန်မှ အရှုံး၊ အကွက်သင်ယူနိုင်ရန် retry အမြန်ပြန်စေပြီး ယခင်သိမ်းထားသောငွေ/အခန်း progress မဆုံးရှုံးရ။

လောက်လေးခွမပါလျှင်လည်း18ချက်သန့်သန့် J ထိရင်နိုင်မည့် စမှတ်ဖြစ်သည်။ K အားပြည့်က6ချက်။ ဒိုင်းကာထားသည့်အချိန်၊ ချဉ်းကပ်မှုနှင့် ရှောင်ချိန်တို့ကြောင့် ဤသည် ကစားချိန်ခန့်မှန်းချက်မဟုတ်ပါ။ Target-specific punch damage ကို Chapter4 သို့တိတ်တဆိတ်မပြောင်းရ။

## 9. စိတ်ကူးဖြင့် ကစားလမ်းကြောင်းစစ်ခြင်း

အောက်ပါသည် စာရွက်ပေါ် စည်းမျဉ်းစစ်ခြင်းသာဖြစ်သည်။ တကယ်စမ်းကစားထားသည်ဟု မယူရ။

**လောက်လေးခွပါသောသူ:** B မှထုတ် → ရှေ့ဒိုင်းကိုပစ်၍ block ကိုသိ → အပေါ်မှတုတ်ရိုက်ကို L/ဘေးရွေ့ရှောင် → ဒိုင်းဖွင့်ချိန်ပစ်။ လှည်းကို တိုးဝင်လမ်းကြောင်း၌ထား → လှည်းနှင့်တိုက်မိလျှင် လှည်းပေါ်ခုန်တက်၍ပစ် သို့မဟုတ် လှည်းကိုကျော်ပြီးဖွင့်နေသောဘက်မှချ။ နောက်ပိုင်း ဦးကြီးလှည်းတွန်းမည့်ပုံကိုဖတ်ပြီး ရှောင်/တား။

**လောက်လေးခွမပါသောသူ:** တုတ်ရိုက်ကိုရှောင် → နားချိန်တွင်အနားကပ် J → ပြန်ခွာ။ လှည်းဖြင့် opening ကြာစေပြီး J ဆက်ချနိုင်သည်။ ဒိုင်းကိုရှေ့ကနေ အဆက်မပြတ်ထိုးနေသည့်နည်းကို အဓိကနည်းအဖြစ်မထားရ။

**အလွန်ကျွမ်းကျင်သောသူ:** လှည်းမသုံးဘဲ committed rush ကိုကျော်ပြီး နောက်ဘက်မှတိုက်ကာ ပိုမြန်နိုင်သည်။ လှည်းပဟေဠိပြထားဖို့ဆိုပြီး ထိုလမ်းကြောင်းကို မပိတ်ရ။

ပထမဆုံး playable စမ်းသပ်မှုများတွင် K ရပ်ပစ်၊ J အဆက်မပြတ်ထိုး၊ ပတ်ဝန်းကျင်သုံးခြင်း၊ လှည်းမသုံးခြင်း၊ လက်နက်မပါခြင်းနှင့် နှစ်ဖက်ထောင့်၌ရပ်ခြင်းကို နှိုင်းယှဉ်ရမည်။ လှည်းကကိုယ့်ပစ်ချက်ကိုကာသည့်အကြောင်း ကစားသူသိနိုင်မနိုင်၊ phase ပြောင်းရာ၌ဖတ်နိုင်မနိုင်ကို စစ်ရမည်။

## 10. Scene 3 — အနိုင်ရပြီးနောက်

ဦးကြီးသွေးကုန်လျှင် လက်နက်ချပြီး လက်မြှောက်မည်။ နောက်ထပ်တိတ်တဆိတ်တိုက်ခြင်း၊ သွေးပြန်ဖြည့်ခြင်း မရှိရ။ လှည်းကို ဘေးကင်းစွာရပ်စေပြီး exit အချိန်ကိုအန္တရာယ်ကင်းအောင်ထားမည်။

**ဦးကြီး:** «ကဲပါ၊ ကဲပါ... ရှုံးပါပြီ။ လမ်းပြခ မယူတော့ဘူး။»

**ဖိုးထောင်:** «လမ်းကတော့ ကိုယ့်ဟာကိုယ် ဖွင့်ခဲ့ရတာချည်းပဲ။ သော့ပေး။»

ဦးကြီးက သော့ပေး၊ တံခါးဖွင့်မည်။ ပိုက်ဆံယူမှဖွင့်ခြင်း မရှိရ။ သော့သည် အဆုံးသတ်စကားပြော၏ staging ဖြစ်ပြီး shop/crafting ပဟေဠိအသစ် မဟုတ်ပါ။

ဦးကြီးက အိတ်ကိုတစ်ချက်ပြန်ကြည့်မိတော့ ဖိုးထောင်က လောက်လေးခွ သို့မဟုတ် လက်သီးကို အသာပြင်ပြသည်။ ဦးကြီးက ချက်ချင်းမျက်နှာလွှဲပြီး အပြန်လမ်းကို ယဉ်ယဉ်ကျေးကျေးပြမည်။ လက်နက်မပါသောသူအတွက် လက်နက်ရှိသလို animation မပြရ။

**ဦးကြီး:** «ဟိုဘက်ကပါဗျာ။ ကျောက်လှေကားအတိုင်း တက်သွားရုံပါ။»

**ဖိုးထောင်:** «ဒီတစ်ခါ လမ်းမှားပြရင်တော့ ခင်ဗျားပါ လိုက်ခဲ့။»

ကစားသူက အပြင်ထွက်ပေါက်ကို ကိုယ်တိုင်ရွေ့၍ ကျော်မည်။ ဤနေရာပြီးမှ အဆုံးသတ်သိမ်းမည်။

## 11. Scene 4 — အပြင်သို့လွတ်မြောက်ခြင်းနှင့် epilogue

နေရောင်အောက်က ရှေးမြို့အပျက်အစီး၊ အဝေးကစေတီများနှင့် အိမ်ပြန်လမ်းကို မြင်ရမည်။ ရွှေမြို့တော်ရှာလာခဲ့သည့်ခရီး အလကားမဖြစ်သွားကြောင်း ပြမည်။

**ဖိုးထောင်:** «ရွှေမြို့တော်တော့ တွေ့ခဲ့ပြီ။ အိမ်ပြန်လမ်းက ပိုရှာရခက်သား။»

အတည်ပြုပြီး main objective အတိုင်း အသက်ရှင်လွတ်မြောက်သူတိုင်း ဂိမ်းပြီးဆုံးနိုင်မည်။ Chapter5 ရန်သူကို လက်ဖြင့်နိုင်/လောက်လေးခွဖြင့်နိုင်၊ လှည်းသုံး/မသုံးမှုက ending ကောင်း/မကောင်းကို မဆုံးဖြတ်ရ။

**ရွှေမလောက်သော ending:** ရခဲ့သမျှရွှေ၏တန်ဖိုးကိုထိန်းပြီး အကြွေးတချို့ဆပ်နိုင်ကြောင်းပြမည်။ ရွှေသုညဆိုလည်း main win ရပြီး ဆက်အလုပ်လုပ်ဖြေရှင်းရန်ဆုံးဖြတ်မည်။ ယခင်အခန်းများကို အကြွေးကျေသည်အထိ မဖြစ်မနေပြန်ကစားခိုင်းခြင်း မရှိရ။

**ဖိုးထောင်:** «ဒီတစ်ခါတော့ အသက်ပါလာပြီ။ ကျန်တာ ဖြည်းဖြည်းချင်း ရှင်းတော့မယ်။»

**ရွှေလုံလောက်သော ending:** အကြွေးရှင်ထံ ဆပ်ပြီး အိမ်ပြန်နိုင်သော ပိုကောင်းသည့် epilogue။

**အကြွေးရှင်:** «ကဲ... အကြွေးကျေပြီ။ နောက်ဘာလုပ်ဦးမလဲ?»

**ဖိုးထောင်:** «အိမ်ပြန်မယ်။ ဒီတစ်ခါ လမ်းတော့ ကိုယ့်ဟာကိုယ်ရွေးမယ်။»

Debt target၊ Chapter3 relic value နှင့် Chapter5 reward amount ကို ယခုအဆိုပြုချက်တွင် မတီထွင်ပါ။ Actual earning budget ဖြင့် ရနိုင်ကြောင်းစစ်ပြီးမှ သတ်မှတ်ရမည်။ Currency သုညတန်ဖိုးဖြစ်သွားစေသော fake-gold reveal မသုံးရ။

Credits နှင့် replay/menu သည် ယုံကြည်ရသော UI ဖြစ်ရမည်။ Victory/credits ပြပြီးနောက်တိတ်တဆိတ်သတ်ခြင်း၊ ပြန်စခလုတ်ရှောင်ခိုင်းခြင်း၊ Chapter6 ဆက်မဖြစ်မနေခိုင်းခြင်း မရှိရ။

## 12. ကစားချိန်၊ production နှင့် လက်ရှိအခြေအနေ

ပထမအကြိမ် ဇာတ်လမ်းဖတ်ခြင်း၊ အကွက်သင်ယူခြင်းနှင့် retry အပါအဝင် Chapter5 ကို အကြမ်းဖျင်း4–6မိနစ်ရည်ရွယ်နိုင်သည်။ သိပြီးသားတိုက်ပွဲလမ်းကြောင်းက ပိုတိုနိုင်သည်။ Cutscene/စောင့်ချိန်ဖြင့်အတင်းမရှည်စေရ။ ဤအချိန်နှင့် fun/originality/replay value ကို မစမ်းသပ်ရသေးပါ။

အဓိကပုံအသစ်မှာ ဦးကြီး boss နှင့် လှည်းတစ်စီး။ Guard၊ တုတ်ရိုက်၊ တိုးဝင်၊ တွန်း၊ ဒဏ်ထိ/နား၊ အရှုံး ဟူသော readable animation sets လိုမည်။ Background ကို လက်ရှိ painted ancient-city look နှင့်ညှိမည်။ ထိမှန်ခြင်း၊ ကာမိခြင်းနှင့် warning ကို ခွဲသိနိုင်သောအသံများလိုမည်။ Art/audio အတည်ပြုခြင်းနှင့် code correctness ကို သီးခြားစစ်ရမည်။

ယခုရေးထားသည်မှာ script/design အဆိုပြုချက်သာ။ Runtime code၊ save/economy၊ assets၊ server သို့မဟုတ် GitHub ကို မပြောင်းထားပါ။ နောက်တစ်ဆင့်က ဤတိုက်ပွဲစည်းမျဉ်းကို review လုပ်ပြီး အခန်း၅ spec/graybox ဖြင့် စမ်းသပ်ရန်ဖြစ်သည်။
